# 大学進学時の都道府県間人口移動

田村一軌「大学進学にともなう都道府県間人口移動」の OD 分析を、グラフ DB で再現・拡張する学習用プロジェクト。

## 何を表すか

ノードは都道府県、エッジは `出身高校所在地 → 入学大学（学部）所在地` の有向・重み付き関係である。エッジの重みは入学者数。これは論文と同じ定義で、18歳前後の進学移動を捉える有力な代理指標だが、住民票や居住地の移動そのものではない。

```mermaid
flowchart LR
  A[高校所在地: 福岡県] -->|ENTERED_UNIVERSITY_IN\n年: 2024\n入学者数: movers| B[大学所在地: 東京都]
```

元データは文部科学省「学校基本調査」の「出身高校の所在地県別 入学者数」。表の行が大学所在地、列が出身高校所在地なので、変換時に `列 → 行` をエッジ方向にする。逆にすると、流出と流入の意味が丸ごと反転する。

## グラフとして見る問い

- どの都道府県が進学者を吸収するハブか: 加重入次数
- どの都道府県が送り出し側か: 加重出次数
- 進学時の純流入・純流出はどこで大きいか: 流入 - 流出
- 特定県はどの進学先に集中しているか: 出辺の重み分布
- 双方向に結びつく地域圏はどこか: 二県間の相互流動

単なる次数中心性は大学定員の規模を再記述しがちである。まず人数・構成比・純流入を分け、必要になってから PageRank やコミュニティ検出を追加する。この順番なら、グラフ指標を政策上の「魅力」と誤読しにくい。

## データを作る

`data/raw/` に2015〜2025年度（平成27〜令和7年度）の大学・大学院「計」表を置いてある。Python 3.11+ を想定する。

```bash
python3 -m pip install -r requirements.txt
python3 scripts/build_od.py                                  # data/raw の全年度
python3 scripts/build_od.py --input data/raw/mext-school-basic-2025.xlsx   # 単年度
```

生成物:

- `data/processed/od_edges_<年度>.csv`: 47都道府県間の県外進学エッジ。県内進学の自己ループは除外。
- `data/processed/prefectures_<年度>.csv`: 県ごとの県内進学、流入、流出、純流入、県外進学率。
- `data/processed/od_edges_all.csv`, `prefectures_all.csv`: 全年度の合算。時系列比較・可視化はこちらを使う。

表にある「その他」は特定の都道府県へ対応付けられないため、47ノードのグラフから除外する。従って、これは都道府県間に閉じたネットワークである。除外量は年に1.5〜2.2万人で、実行時に年度ごとに表示する。

### 表レイアウトの年度差

セル位置は決め打ちせず、県名の一致でヘッダ行と行見出し列を検出している。年度で表の形が変わるためである。

| 年度 | 「1 計」表 | 列見出し | 行見出し |
| --- | --- | --- | --- |
| 2015-2020 | 2シートに横分割（北海道〜愛知 / 三重〜沖縄） | 「青　森」（全角スペース、接尾辞なし） | 同左 |
| 2021 | 1シート | 「青森県」 | 「青森」 |
| 2022-2025 | 1シート | 「青森県」 | 「青森県」 |

読み取り後、大学所在地ごとに `47県の合計 + その他 = 表の「計」列` を検証する。1件でも合わなければ変換を中断する。

## ヒートマップで見る

`viz/index.html` をブラウザで開く。縦軸が出身高校の所在地、横軸が大学の所在地の47×47。時系列スライダで2015〜2025年度を送り、再生すると年度間を補間しながら遷移する。

```bash
python3 scripts/build_viz_data.py     # data/processed から viz/data.js を再生成
open viz/index.html
```

- 実数: 入学者数。対角線上の県内進学を含む。桁の開きが大きいのでべき乗（0.35）で色付けする。
- 流出構成比: 出身県の県外進学者に占める割合。対角線上は分母から外し、灰色で示す。

配色は OS の設定に従うが、画面上のボタンで明暗を切り替えられる。暗色側は逐次ランプを反転しただけでは最小値が濃紺のまま光って盤面が埋まるため、最下段を背景色に落として立ち上げている。

## 受け入れ規模（設置者別）

同じ xlsx には「1 計」のほかに「2 国立」「3 私立」の表がある。そこから大学所在地ごとの入学者数を取り出す。公立の表はないので `計 − 国立 − 私立` として求め、負にならないことを検証している。

```bash
python3 scripts/build_capacity.py       # data/processed/capacity_<年度>.csv と capacity_all.csv
```

この人数は各表の「計」列、つまり全出身地の合計であり、都道府県に対応付けられない「その他」を含む。OD グラフの47県に閉じた数より大きくなる。県の受け入れ規模を見る数字なので、こちらを採っている。

全国では国立が約10万人、公立が約3.5万人、私立が約50万人で推移する。県ごとの差は大きく、2025年度の京都府は36,549人（国立3,831 / 公立1,093 / 私立31,625）、鳥取県は1,634人（国立1,221 / 公立328 / 私立85）である。

## 学校数（2025年度の断面）

学校数は別表なので、令和7年度ぶんだけ取得してある。年度をまたぐ時系列ではなく、1年の断面として使う。

| ファイル | 出典（e-stat statInfId） |
| --- | --- |
| `data/raw/mext-university-count-2025.xlsx` | 大学「7 都道府県別 学校数及び学生数」000040392726 |
| `data/raw/mext-highschool-count-2025.xlsx` | 高校「122 都道府県別学校数（3-1）」000040393775 |

```bash
python3 scripts/build_schools.py       # data/processed/schools_2025.csv
```

設置者別の内訳が計と一致することを県ごとに検証している。全国では高校4,761校、大学812校。

### 突き合わせて分かること

- 大学数と高校数の相関は +0.91（決定係数0.84）。大学数の情報の大半は県の規模の言い換えである。県外進学率との相関は大学数が −0.69、高校数が −0.68 とほぼ同値で、大学数を持ち出しても高校数以上のことは言えていない。
- しかも大学は規模に比例ではなく逓増して置かれる。両対数の傾きは1.29で、高校数が2倍の県は大学数が約2.4倍になる。高校数下位12県の「高校100校あたり大学数」は平均12.1、上位12県は17.7。
- 効くのは規模を割り落とした比である。高校100校あたりの大学数と県外進学率の相関は −0.65、受け入れ倍率（その県の大学の入学者 ÷ その県の高校からの進学者）と県外進学率は −0.72。倍率は東京を除いても −0.68、順位相関でも −0.72 で、外れ値に強い。
- 同じ大学数でも需要側が違えば結果は反転する。大学14校の石川は県外進学率51%（高校56校、倍率1.14）だが、同じ14校の静岡は71%（高校136校、倍率0.47）。大学8校でも沖縄58%、福島80%と割れる。
- ただしこれは1年の断面の相関であり、因果の向きは決められない。大学があるから残るのか、若者が残る規模の県だから大学が成り立つのかは、このデータからは分離できない。
- 倍率が1.0を超える、つまり送り出しより多く受け入れるのは京都2.24、東京2.02、大阪1.28、福岡1.17、石川1.14、宮城1.14、愛知1.12、神奈川1.05 の8県のみ。最低は茨城0.38で、純流入も全国最下位（-10,541）。
- 密度が高くても流出する例がある。奈良は高校100校あたり20.4校と上位だが県外進学率85%で、大阪・京都に吸われている。密度は必要条件であって十分条件ではない。
- 大学1校あたりの入学者数は流出とほとんど関係しない（相関 −0.42）。神奈川が1,460人で最大だが県外進学率は59%、佐賀は大学2校で923人と上位に来る。少数の大規模校と、そもそも学校が少ない県が同じ値を取るため、単独では読めない指標である。

## 設置数と流出を突き合わせて見る

`viz/schools.html`。2025年度の断面のみ。

- 上段は都道府県別の大学数を設置者別の積み上げで並べる。大学数順、高校100校あたり順、北から順で並べ替えられる。
- 下段は散布図で、縦軸が県外進学率、横軸は受け入れ倍率と高校100校あたりの大学数を切り替えられる。円の色は純流入、大きさは高校数。回帰直線と相関係数を出す。

## ノードとエッジで見る

`viz/graph.html`。ノードが都道府県、矢印が「出身高校の所在地 → 入学した大学の所在地」。ヒートマップと同じ `viz/data.js` を読む。

- ノードの位置は県庁所在地のおおよその座標。沖縄県だけ九州の南西へ寄せている。
- ノードの色は純流入の発散配色。大きさは送り出し（その県の高校から進学した人数）と受け入れ（その県の大学に入った人数）を切り替えられる。
- カーソルを乗せると、その県の大学の入学者数と国公私立の内訳が出る。
- 矢印は出発側が太く行き先へ細くなる帯で、終点に矢じりを置く。矢じりだけに向きを頼らせない。
- しきい値スライダで表示する流れを絞る。2025年度なら500人以上で120本、県外進学者の66%を覆う。
- 県にカーソルを乗せると、その県の流出（赤）と流入（青）だけが色付く。クリックで固定すると、しきい値を無視してその県のすべての流れを出し、関係のない県は沈む。
- 全国・東日本・西日本の切り替えで、表示範囲に合わせて投影を組み直す。東日本は北海道〜愛知、西日本は三重〜沖縄で、中部と近畿の境で切っている。

色の定義域は全年度で固定してあるので、年をまたいだ濃さの比較がそのまま成り立つ。補間はあくまで色であって、ツールチップの数値は常に最寄り年度の実数である。`viz/data.js` は fetch を使わずに済ませるための単一ファイルで、`file://` のままでも開ける。

## Neo4j に読み込む

1. Neo4j Desktop でローカル DB を作る。
2. `data/processed/` の2 CSVを DB の `import` ディレクトリへコピーする。
3. [graph/import.cypher](graph/import.cypher) を Neo4j Browser で実行する。
4. [graph/analysis.cypher](graph/analysis.cypher) のクエリを順に実行する。

関係型の OD 表を、次の形へ変えている。

```text
(:Prefecture {name})-[:ENTERED_UNIVERSITY_IN {year, movers}]->(:Prefecture)
```

年度を関係プロパティに持たせるので、同じスキーマのまま複数年度を重ねられる。年次比較では年度ごとに同じ閾値を使い、絶対人数だけでなく各出身県の県外進学者に占める構成比も確認する。

## 注意点

- 同じ県の大学へ進学した人は「移動」エッジから除外するが、ノード属性 `local_entrants` として残す。
- 大学所在地は大学本部ではなく入学した学部の所在地。
- 出身高校所在地は卒業時の居住地と一致するとは限らない。
- 論文の重力モデルは、OD 人数を目的変数とし、距離・所得・大学教育条件などを説明変数に加える段階である。このプロジェクトのグラフ分析は、まずその前の構造把握を担当する。
